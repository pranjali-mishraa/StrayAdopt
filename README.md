# StrayAdopt

StrayAdopt is a full-stack web application that helps people post and discover stray pets available for adoption.

## Features

* User registration and login
* Post stray pets for adoption
* Upload up to 5 images per pet
* Add pet description and location
* Browse recently added pets
* Explore all available pets
* Adoption status tracking
* User-to-user messaging
* Responsive user interface

## How It Works

1. Create an account or log in.
2. Post information about a stray pet.
3. Upload images and add its location and description.
4. Other users can browse available pets.
5. Interested users can contact the post owner through messaging.
6. The pet's adoption status can be updated once adopted.
